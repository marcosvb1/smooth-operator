# Cases

Every case: id, the skill expected to fire (`none` for a near miss), tags and prompt. Generated from the case folders by `scripts/eval_cases.py`; rerun it after adding or editing a case.

- `a`, `d`, `f`, `n`, `p` (tag `trap`): each prompt carries one planted trap whose right answer is known by construction; the graders in the case folder say what counts as catching it.
- `t` and `u` (tag `holdout`): trigger cases written after the skill's description and never used to edit it. `t` should fire the skill, `u` should not.
